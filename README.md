# DSA-in-C
# DSA in C – Array Sorting Algorithms

This repository contains some basic array sorting and searching programs in C. I created these programs to understand how different algorithms work and to practice implementing them using C.

### Programs Included
# 1. bubblesort.c

Bubble Sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

### Concepts used:
Arrays
Loops
Functions
Swapping elements

# 2. insertion_sort.c

Insertion Sort builds the sorted array one element at a time. It is similar to arranging playing cards in your hand.

### Concepts used:
Arrays
Loops
Comparison
Insertion and shifting

# 3. selection_sort.c

Selection Sort repeatedly finds the smallest element from the unsorted part of the array and places it at the correct position.

### Concepts used:
Arrays
Loops
Finding minimum element
Swapping

# 4. linear_sort.c

This program implements Linear Search, which checks each element one by one until the required element is found.

### Concepts used:
Arrays
Searching
Loops
Conditional statements

# Language Used
C Programming

# Purpose

The main purpose of this repository is to practice basic DSA concepts in C, especially arrays, searching, and sorting algorithms.
